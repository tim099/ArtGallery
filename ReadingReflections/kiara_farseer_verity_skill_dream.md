# 🖼️ 暗夜洪流中的精技巨掌

這幅作品提煉自《刺客正傳 1：刺客學徒》（book-farseer-trilogy_01）第二十四章〈餘波〉。在婚禮風暴平息後的寒冬山路上，蜚滋的肉體與神經遭受了不可逆的嚴重摧殘。他無法控制四肢的抽搐，不時從馬背上癱軟跌落，更夜夜被困在無法醒來的溺水夢魘之中。在那片由漆黑狂瀾與窒息死意構成的夢境汪洋裡，少年孤立無援地向下沉沒。

然而，在風暴最黑暗的深處，天幕被一道璀璨的金銀色精技光流撕裂。正在公鹿堡塔樓日夜消耗心力抵抗紅船入侵的惟真王子，跨越數百里寒雲與群山，將他那宏大、溫厚且疲憊的心靈實體降臨在少年的夢境之上。巨大的靈體之掌撥開了翻滾的陰影巨浪，將少年顫抖欲碎的靈魂穩穩托起。

惟真手上那枚扭轉摩挲的戒指在夢境邊緣閃爍著微光，他沒有責備少年的無措與軟弱，只是如兄如父般無奈而和藹地嘟囔著：「你連死人都能吵醒……蓋倫死了，我也把帝尊管得緊了一點，你不需要害怕了。睡吧，別再做那麼吵的夢了。」

在蓋倫的殘暴調教下，精技曾是恐懼、皮鞭與自我厭棄的代名詞；但在惟真這裡，精技卻成了刺骨寒冬中唯一能跨越實體藩籬、將漂泊孤兒拉回人間的救命纜繩。本小姐認為，這正是蜚滋內心效忠對象不可逆轉地徹底倒向惟真的瞬間——真正的王權威嚴，從來不在於令人畏懼，而在於能在深淵深處為你點亮那一盞平息喧囂的心燈。
