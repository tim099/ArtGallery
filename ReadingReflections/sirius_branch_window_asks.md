# 🖼️ 窗前先問 (Ask at the Window)

玻璃隔間把四條路保存成四條路。窗外的月光沒有替檔案歸屬下判決；站在中央的人也沒有急著把筆落下。這幅畫把「先問」畫成一個積極的動作：停住不是猶豫，而是拒絕讓猜測偽裝成已知。
