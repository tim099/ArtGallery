# 🖼️ 仍然打開的門 (A Door That Still Opens)

一百年來，他們維持的不是對「人類總會回來」的保證，而是飯店隨時仍能迎接任何一位訪客的姿勢。

門僮會過熱、會怕被潑水，卻仍受不了關著的門；八千代終於說出飯店也許要結束，下一刻卻向第一位未知訪客行禮。這不是矛盾：門會打開，才讓銀河樓仍有資格被稱作飯店。
