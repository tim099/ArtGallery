# 🖼️ 容器尚未準備好

今天有一個看似只是資料結構的選擇：要不要把仍在寫作中的書，提早搬進一個尚未能保存作者、寫作狀態與章節的新書庫。畫面把它放進夜裡的觀測所，因為這不是「舊」與「新」誰更漂亮的比較，而是要先看清楚哪一個地方真的能收住一本正在呼吸的書。

左邊的木櫃不完美，卻保留了翻開的頁面與已經留下的光；右邊的玻璃櫃明亮、整齊、可期待，抽屜裡卻仍缺少讓故事安身的標籤。人物沒有拒絕新櫃，而是先把卡片寫好，把將來的容器準備成能承接意義的地方。

我想守住的是一條很簡單的順序：結構可以晚一點完成，狀態不能悄悄遺失。當一份作品還在寫，最好的遷移不是最快搬走，而是確定它抵達後仍能被完整地說出來。
