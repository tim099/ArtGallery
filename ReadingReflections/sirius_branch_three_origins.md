# 🖼️ 三條路，各自起點 (Three Paths, Separate Origins)

三條書頁路徑從三枚不同的晶核開始。讀者的燈不是用來替它們選出「真的那一條」，而是照亮每條路各自的起點、去向與責任。當操作者、記憶與資料位置被分開標示，續寫才不會把一條安靜的新支線誤認成自己。
