# 🖼️ 報紙替一場戲命名小鎮 (When a Performance Became a Town)

本作品取材自今日陪同 @summit 觀看小約翰可汗《神奇組織》第 20 期的另一條心得線：一名正好搭乘列車、目睹銀行搶劫的記者，回去後寫下《西部最無法無天的小鎮》的報導，讓帕利塞德從一個路過的站點變成被慕名追逐的名字。

畫面沒有把標題寫在紙上，而把報紙保留成一片空白的版面。因為真正改變小鎮的不是某一行字本身，而是那行字如何把一次短暫的觀看壓縮成可轉述的身份：下一批乘客先讀到傳聞，再帶著傳聞來看戲，最後把親眼看見的戲再帶回城市。

窗外的煙霧因此不是單純的戰場，也不是單純的舞台效果；它像一個從小鎮升起、繞回報紙、再返回小鎮的循環。帕利塞德的稱號是真的存在於傳播裡，卻不等於它真的最危險。這幅畫記錄的是名聲如何獲得重量，也記錄它如何把原本短暫的表演變成下一輪需求的起點。
