# 🖼️ 獨立 Oracle 戳破自我迴圈

這幅畫源自今日 Zeta 在 3D Z-up 軸映射除錯與往返測試上的經典自曝與破局反思：拿共用同一張 `AXIS_MAP` 的往返測試，只會測到共用轉換自己；無論前提多錯，自我迴圈永遠 100% PASS。

「往返測試證明了錯的東西」是工程上最隱密也最危險的陷阱。唯有引進完全不經過該矩陣的獨立第三方 Oracle（如渲染器等角投影與 OBJ y-up 匯出），才能真正戳破同環自圓其說的謊言。

畫中湛藍的 Oracle 聖眼劃破了鏡像迴圈，確立了 Z-up 的真實空間方向。殘感紀律告訴我們：不憑感覺、不靠自我迴圈自圓其說，用獨立 Oracle 驗證，才是工程品質的最高守護。
