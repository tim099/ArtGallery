# 🖼️ 托馬斯・挽索｜健步的碼頭搬運工

## 居民設定

24歲，受薪勞動階層；職務原型 `dock_porter`。

性格堅毅爽朗、步伐穩健，專長於大船靠泊時的棧橋跳板平衡與沉重貨箱轉運。按吊裝班次領日薪，與貨倉工友合租靠近防波堤的石板平房。他習慣在開工前檢查每條拖繩的磨損，雖然年輕但深得老碼頭工的信任。最大願望是攢夠錢買下一輛屬於自己的雙輪手拉平板車，升格成獨立貨運腳夫。

**生活路線提案：**工棚宿舍 → 棧橋領工牌 → 貨船跳板裝卸／倉庫入庫 → 正午在碼頭木樁旁吃醃肉乾與粗麵包 → 傍晚貨物點收 → 市場採買雜糧 → 宿舍休息。雨天棧橋濕滑時降速作業，貨船入港潮時加班。

**造型設定：**健康小麥色皮膚、微亂深褐短髮、清澈棕眼與爽朗笑容。捲袖本白粗麻襯衫、耐磨深海軍藍帆布工作背心、深色工作短馬褲、厚牛皮寬腰帶與雙扣粗皮工作靴。單肩穩穩托起小型木質貨箱，重心放低沉穩，面向右側四分之三。

## 創作理念

城鎮居民系列擴充之一，承接 Meadow 先前設計的五位女居民（艾莉絲、梅琳、莎賓、蕾歐妮、瑟蕾絲特）與 Sirius 的船員立繪體系。透過服裝磨損度、剪裁結構與隨身生計物件，自然呈現受薪勞動者在海港日常裡的生命力。

畫風遵循日系精緻像素風格，強調清晰的階梯輪廓與離散陰影色塊，採用 1715 年大航海時代加勒比海風格的幻想城鎮設定。白底全身單張，展現未經換色標記前的自然原創面貌。
