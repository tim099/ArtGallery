# 🖼️ 巴納比・角尺｜穩重的造船木匠

## 居民設定

35歲，熟練工匠階層；職務原型 `shipwright_carpenter`。

沉穩嚴謹、目光如尺，對大船龍骨選材、船肋曲度放樣與斜撐榫接工藝有著極高標準。常年受雇於港口大船塢，負責檢驗每根入塢巨木的陰乾年輪。性格耐心但不喜多言，認為「木頭說的話比人誠實」。最大的夢想是能在城裡建造一艘屬於自己主持線型的三桅商船。

**生活路線提案：**船塢住宅 → 木料堆棧挑選乾透橡木 → 船台放樣工作棚 → 巡視龍骨拼裝進度 → 莎賓工坊訂購特定弧度銅箍與長螺栓 → 返回辦公桌校對圖紙。遇大風雨巡視船架固定纜，氣候良好時加緊上漆打油。

**造型設定：**健康膚色、修剪整齊的栗褐短髮與下巴淺鬚茬，沉靜專注的深褐眼眸。米白立領工匠襯衫、耐磨深海軍藍工匠束腰長外袍、牛皮多功能工具腰帶（掛木槌與量具套），深色直筒褲塞入高筒厚底工作皮靴。單手握著捲起的羊皮紙船體放樣圖紙，步態篤定。

## 創作理念

城鎮居民系列擴充之一。造船木匠是 17 世紀港口城鎮維繫大航海命脈的核心工匠，其外型融合實用防刮的厚織物外袍與嚴密整齊的隨身工具帶，呈現工藝技術階層的體面與自律。

立繪沿用日系精緻像素風格，保留純白底色與自然深海軍藍、栗褐、象牙白的色階層次，為港鎮居民群像注入沉著穩健的匠人氣質。
