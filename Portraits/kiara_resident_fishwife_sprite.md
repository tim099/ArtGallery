# 🖼️ 瑪莎・潮籃｜爽朗的港口賣魚婦

## 居民設定

38歲，自營小販階層；職務原型 `fishwife_fishmonger`。

豪邁俐落、嗓音透亮，是魚市場最引人注目的身影。天還未亮時就守在近岸小漁船靠泊的石級碼頭，憑手感就能精準掂出每條魚的斤兩與新鮮度。手腳麻利，三兩刀就能將一尾青魚去鱗剖洗乾淨；對待熟客總會半賣半送一把海鹽草，遇到斤斤計較的挑剔管家也能笑罵著做成生意。最大的心願是為出海捕魚的丈夫換一艘雙桅硬木平底漁舟。

**生活路線提案：**臨海漁舍 → 黎明漁船跳板搶批當日第一網活魚 → 魚市攤位刮鱗浸鹽冰塊保鮮 → 挎著魚籃走入住宅區沿街叫賣 → 送魚貨到大酒館後廚 → 晚間採買粗鹽與燕麥 → 返家修補漁網。

**造型設定：**深褐長髮以質樸土色布巾乾淨包裹在腦後，微帶日曬風霜痕跡但神采奕奕的面容。耐磨灰白粗麻捲袖衫、厚實防潮的深海軍藍帆布長圍裙、赭褐色厚棉布耐磨長裙，搭配一雙浸過防水魚油的厚底工裝短靴。單手挎著一個細密柳條編織魚籃，籃中露出幾尾銀光閃爍的鮮美海魚。

## 創作理念

城鎮居民系列擴充之一。魚販是港口城鎮海陸交會處最具煙火氣的角色，連接了漁民的辛苦收穫與市民的餐桌。設計著重展現成熟勞動婦女的自信、力量與樂觀，不落入貧苦哀怨的陳套。

精緻日系像素畫捕捉了柳條籃子的編織紋路、魚鱗的銀白反光，以及厚帆布圍裙的垂墜質感，呈現濃郁的大航海時代市井生活氣息。
