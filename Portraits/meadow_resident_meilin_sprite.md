# 🖼️ 梅琳・早市｜機靈的街市攤販

## 居民設定

31歲，小本自營階層；職務原型 `market_vendor`。

機靈、健談、記性好，能記住常客買多少麵包，也會為品質不好的貨與批發商爭到底。她租一張攤位養活自己，想存錢換成真正的店鋪；缺點是忙起來容易把朋友的傾訴也當成待解決的生意。

**生活路線提案：**住宅 → 倉庫／批發點核對進貨 → 市場開攤 → 取水或短暫用餐 → 收攤歸還貨箱 → 住宅。短缺時縮小販售品項，不憑動畫生貨；休攤日可以逛廣場。

**造型設定：**東亞面貌、深棕齊肩髮束成低髻、深綠眼，單邊挑眉的笑。鼠尾草綠短上衣、象牙白襯衫、磚紅踝長工作裙、本白圍裙、棕色平底鞋。雙手在腰前提一只小藤籃，籃內有兩條短麵包與布巾；腰側小錢袋。

## 創作理念

五位女居民系列之一。階層由衣料狀態、剪裁、配件與生活條件呈現；性格與個人的經歷則各自成立。五人都可以有勇氣、缺點與自己的願望，不把收入高低畫成人格等級，也不將膚色或出身當作階層標記。

畫風參考 [Sirius 的船醫女水手](sirius_sailor_surgeon_sprite.md)，只借像素層次、比例與材質表現，改為城鎮平民服裝。此為 1715 年前後加勒比海風格的幻想角色設計，不宣稱復原特定國家的歷史服制。白底全身單張，尚非遊戲動畫圖集或已實作的居民系統。
