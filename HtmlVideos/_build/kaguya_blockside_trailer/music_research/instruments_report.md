## 量法

腳本是 `scratchpad/instr_lab/instr_lab.py`（不在 repo 裡）。用法：`python -I -X utf8 instr_lab.py --wt <bs_music> --out <資料夾> [--only …] [--demos demos.json] [--calib]`。
它開一個無頭 Chrome（port 9361，同時只開一個，跑完就關，量完確認過沒有殘留的行程），呼叫 `__game.bgmRender({ abc })` 離線錄音。

- **音高、音頭**：直接用 `src/tests/music_lab.py` 的 `f0`／`pitches`／`onsets`，一行都沒改。
  - 音準段：一個音一拍、後面空一拍（撥弦類空兩拍），每個音前後都空開。
  - 和弦的音不量音高，因為同時響的兩個音會互相干擾。
- **響度**：A 加權（IEC 61672 曲線，在頻域乘上去），算單聲道平均之後的 RMS。
  - **先校正量尺**：用同一支函式量四首船歌整段，得到 −25.14／−24.40／−24.89／−24.44 dB。README 寫的是 −25.1／−24.4／−24.4／−24.9，同一組數字，所以這把尺跟上次對齊用的是同一把。
- **「跟提琴同一個響度級」怎麼量**：每種樂器的樂句段（在它自己的音域、mf），把 `[I:]` 換成 `fiddle` 再錄一次，算兩者的 ΔA。
  - 舊的六種彼此之間本來就差：手風琴 +1.1、音樂盒 +0.7、錫口笛 −0.7、撥弦 −2.3、管風琴 −3.7 dB（同一段 D4–D5 的譜）。
  - 所以我把目標訂在「落在這個範圍裡、盡量靠 0」。
- 另外量的：
  - 起音：到最大值 −3 dB 要幾 ms。
  - 衰減 t30：最大值之後掉 30 dB 要幾秒。
  - 頻譜重心：看音色有沒有跟著力度變。
  - 共振峰、倚音、滾奏：各一組專門的讀數，在下面各自那一節。
- 試聽頁：`scratchpad/instr_lab/out/d/index.html`，114 MB 的 WAV。
  - 每種樂器有兩段：它自己的樂句、同一段換提琴的對照。
  - 研究員交的八首候選曲，各錄前 32 秒。

### 專門的檢查

- **詠唱團的共振峰**：從幾個長音收集各泛音的振幅，每 100 Hz 取一個包絡。
  - 峰在 **650 Hz（0 dB）、1150 Hz（−6.8）、2650 Hz（−21.3）**，就是男聲「啊」的 F1／F2／F3。
  - 第一版 F1 被低通那條（基音）蓋掉，平在 350–650 Hz；把低通縮到 f×1.2、份量 0.12，F2 加到 0.8 之後才分出來。
- **銅管有沒有跟著力度變亮**：頻譜重心（Hz），p → mf → f。
  - brass：F4 1522 → 1892 → 2069；C5 2264 → 2766 → 2990。
  - horn：D4 803 → 974 → 1059；A4 1228 → 1462 → 1572，整體最暗。
  - trumpet：D5 2332 → 2716 → 2900；A5 3270 → 3783 → 4011，最亮。
  - **大鍵琴**：C3 1523 → 1533 → 1533、C4 2940 → 2937 → 2945，音色不變；只有峰值跟著力度（−18.6 → −14.5 → −12.6 dB）。
- **十六分倚音（荷蘭人的 B♭，0.104 秒）**：用 `!f! A6 _B/2A11/2…`、𝅗𝅥＝72 量。
  - horn：B♭ 那一段比後面的 A 大 **+2.0 dB**，音高 −0.4～0 cent。
  - trumpet：+1.4 dB；brass：+5.7 dB。
  - 都吹得出來。原因是起音最多佔音長的 30%，加上起音會衝過頭。
- **定音鼓滾奏**：用 4.3 秒的 D3 量。
  - 高頻（> 700 Hz，槌頭）包絡的峰：**每秒 13.9 下**（設計 14 下，每下間隔照 `bgmLcg` 抖 ±10%）。
  - 滾的時候平均比第一下（重音）小 **6.3 dB**，20 ms 視窗的起伏 3.5 dB；一直撐到音尾，沒有衰掉 30 dB。
  - 做法：模態振盪器只開一份，每一下把各模態的增益重新拉上去。所以 35 下只用約 16 個節點，自動化事件約 500 個。
- **定音鼓音高偏高 5–6 cent 的原因**（numpy 照同樣的模態合成，逐項拿掉來對）：
  - 單獨一個衰減中的低音正弦（110 Hz），`music_lab` 的自相關就讀 +1～+1.5 cent。原因是沒有正規化的自相關，加上衰減的包絡。
  - 滑音再加 1～2 cent。
  - 其餘來自 1.5 倍模態。把它拿掉之後，總讀數掉到 +1.2～+1.4。
  - 主音 (1,1) 本身就是譜上的音。我沒有把整組模態往下拉來「騙」讀數，因為那樣頻譜上的主音會變成偏低。
  - 原本 25 cent 的滑音讀 +6.2～+7.0；改成 20 cent、30 ms 之後讀 +4.7～+6.4。
- **箏的衰減**：t30（衰到 −30 dB）E3 2.38、A3 2.24、B3 2.05、E4 1.82、A4 1.44、E5 0.97 秒。研究員要的是低音 2–3 秒、高音約 1 秒。
  - 音高 +2～+4 cent，是硬弦的泛音往上偏造成的，B 已經從 4e-4 減到 2.5e-4。
- **舊的六種沒被動到**：四首船歌的 A 加權讀數，改之前、改之後一樣，都是 −25.14／−24.40／−24.89／−24.44。

## 研究員的候選曲（給下一個人對 vol）

用新樂器錄前 32 秒，`vol` 都還沒寫。目標照 README 是 −24.3～−25.1 dB。

**給下一個人的四件事**：

1. **`vel` ＝ 力度記號 × 整首的 `vol`**。brass／horn／trumpet 的濾波跟著 vel 走，所以 **`vol` 調小，銅管也會跟著變暗**。荷蘭人大概要 `vol` ≈ 0.55，法國號會比 mf 還暗一些。
   - 要分開，得在 `bgmSched`／`bgmRender` 把 vol 跟力度分成兩個參數。這一輪只准改 INSTR，所以沒做。
   - 大鍵琴的音色不看 vel，所以不受影響。
2. **定音鼓滾奏照秒數判斷**（`BGM_ROLL_S` ＝ 2 秒）：
   - 荷蘭人 2.48 秒的長音 ⇒ 滾，`A,,2` ⇒ 一下。
   - 感恩讚的附點二分 1.59 秒 ⇒ 一下。
   - **感恩讚最後一小節的 `D,8`（2.14 秒，再加漸慢）會滾**。收尾滾奏很常見；不要的話，把它改成 `D,4 z4`。
3. 峰值 1.00 的那兩首，離線錄音被 `audioWav` 夾掉一點，A 加權讀數會略偏小。`vol` 先降下來之後再量就準了。遊戲裡 bgmBus ≤ 0.5，不會破。
4. 研究員都提過的 `bgmFrame` 問題：帶 `abc` 的曲子放進 `TUNES` 輪播會被當成主題曲換掉。我沒動，這是 TUNES／THEMES 那一輪的事。

## 自己覺得哪一種還不像（我沒有耳朵，以下是照合成方法推的，要等 Tim 聽）

1. **`choir` 最沒把握**。共振峰量得出來，但鋸齒進帶通的做法容易聽起來像「聲碼器的人聲墊子」，因為沒有真人聲帶的 jitter／shimmer，母音也一直停在「啊」。
   - 譜寫在 D4–C5，男高音的音域。研究員說真正的男聲常低一個八度唱，樂器不幫譜移調；要低八度，改譜就好。
2. **`bassdrum`**：整段 A 加權比提琴小 4.8 dB。瞬時響度跟提琴差不多（−0.4），但它的力氣在 60–110 Hz，A 加權扣掉，筆電小喇叭也放不出來。小喇叭上聽到的主要是 350 Hz 的「噗」跟槌頭。
   - 再加大的話峰值會超過 1，所以停在這裡。
3. **`koto`**：沒有押し、後押し、引き色這些左手的音色。金屬感只靠一點點不諧和的泛音，加上爪子的雜訊，可能聽起來偏「豎琴、卡林巴」，不夠像箏。
4. **`lute` 跟舊的 `pluck`** 差在比較暗、低音撐得久、低音有八度弦。差別不大，可能分不太出來。
5. **定音鼓滾奏**：用的是一直在響的同一組振盪器，每一下把音量拉上去，所以相位是連著的。真的滾奏每一下的相位是亂的，這種做法可能聽起來比較像「顫音」。槌頭雜訊每一下都有，這一點應該能補回一些。
6. **`trumpet`／`brass`**：銅管的「亮」只靠濾波跟起音衝過頭，沒有真的唇振非線性（音量大時波形變陡）。f 的「刺」可能不夠。
7. `fife`、`snare`、`timpani` 單擊、`harpsichord`、`horn`、`drone`：我覺得照方法來說應該像，但同樣沒聽過。
