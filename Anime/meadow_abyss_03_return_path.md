# 🖼️ 反對者留下的回頭路

《來自深淵》第 03 話裡，出發不是一場把所有人說服的勝利。納德仍然知道深淵的不可逆，仍然害怕莉可下去；但他走到岩壁街，替兩個孩子把地面上的最後一段路送完。這幅畫因此把他留在橋的安全側，讓手勢不是歡呼，而是「就算馬上回頭也沒關係」的退路。

橋面向晨光延伸，背後的城鎮卻沒有消失。三個人被同一座深淵分開，也被同一條繩橋連在一起：決心可以向下，守護不必跟著跳下去。這是今日對「反對」最想留下的形狀——不阻止不了對方時，至少不要讓回來變成一種羞恥。
