# 《憲法號對轟》的重產工具

`HtmlGames/ame_constitution_broadside.html` 是由這裡的 `template.html`、`js/`，加上共用的 `VoxelKit/` 產生的：

| 檔 | 做什麼 |
|---|---|
| `template.html` | 版面、HUD、選單（模式、航行、距離、進水速度／船殼硬度／死傷降旗三條滑桿、三個降旗勾選）；引用 `../../../VoxelKit/voxelkit.js`、`js/*.js`（照順序、`data-bundle="game"`）、船的 `.vxk` 與 `art/` 的選用素材 |
| `js/` | 遊戲本體，照功能分檔（下表）；建置時接成同一個閉包 |
| `art/`（選用） | 美術素材 `crew.png`、`fx.png`、`hud.png`；規格在 TASK-0516。沒交 ⇒ 程式畫的替代品 |

```bash
# ① 船：basecamp 的《憲法號（組裝）》，1:1，連繩、帆、模型、關聯外框（認砲位要用）
python -I ../../../VoxelKit/voxel_export.py --work basecamp-frigate-constitution-01m-assembly --out ../../../VoxelKit/_cache/constitution.vxk --rig --models --parts
# ② 內嵌成單檔
python -I ../../../VoxelKit/vxk_inline.py template.html ../../ame_constitution_broadside.html
```

作品之後還會再長；重跑 ① 就拿到現況（`.vxk` 不入版控）。

## 遊戲本體 `js/`

檔名前面的數字就是順序（template.html 照這個順序列，`vxk_inline.py` 照這個順序接）。各檔**沒有自己的作用域**：
建置時接成同一段、包進 `(function () { 'use strict'; … })()`，跟拆開之前是同一個閉包 —— 共用變數與函式、不掛到 window。

| 檔 | 管什麼 |
|---|---|
| `00_core.js` | 網址參數（`?demo`／`?seed`／`?debug`…）、有種子的亂數、常數、向量與矩陣小工具 |
| `01_gl.js` | WebGL 環境、著色器（體素、碎屑、模型、帆 `P.sail`、粒子、海、天）、共用 uniform |
| `02_audio.js` | 音效（按下開始後才建） |
| `03_camera.js` | 鏡頭（自由／追砲彈／看敵艦／看我艦、跟船） |
| `04_state.js` | 全域狀態與選單設定：`LIM`（滑桿上下限）、硬度／進水／航速／靈活性、降旗規則、模式、`PHYS` |
| `10_ship.js` | 開一艘船：砲位、模型、繩與帆的錨、桅、船員（`makeShip`） |
| `11_rig_gpu.js` | 繩與帆的 GPU 緩衝（還綁著的繩、帆的網格 `sailBuf`、垂下來的繩） |
| `12_effects.js` | 碎屑（每格一顆小方塊）與粒子（煙、水花、火光） |
| `20_shatter.js` | 拆格：砲彈打碎船殼 |
| `21_gunnery.js` | 開砲、齊射、射界、砲彈飛行與命中、模型被打飛、鏈彈斷繩撕帆、帆掉下來 |
| `22_pieces.js` | 斷開的那一團：倒下、壓到人、落水 |
| `30_rig_physics.js` | 帆與繩的物理（可關） |
| `31_sailing.js` | 航行：航速、操舵、帆裝、航跡、擦撞 |
| `32_hull.js` | 進水、傾斜、沉沒；每半秒的 `survey`（砲、桅、繩、帆、腳下）與降旗 |
| `40_crew.js` | 船員：站位、操砲、人手集中、傷亡、火槍 |
| `41_crew_art.js` | 船員貼圖（程式畫的替代品／美術素材） |
| `50_sim.js` | 電腦（瞄準、開火）與固定步長的一步 `step()` |
| `60_render.js` | 畫一格 |
| `61_hud.js` | HUD、砲列、左下羅盤 |
| `70_flow.js` | 開局（`reset`／`start`） |
| `71_input.js` | 輸入與選單（鍵盤、滑鼠、按鈕、滑桿） |
| `90_main.js` | 主迴圈、`?debug=1` 的 `window.__game`、載入 |

- ⛔ 新的頂層名字先搜一遍有沒有撞名（同一個作用域：以前船員的 `kill` 蓋掉碎屑的 `kill`）。
- ⛔ 頂層的敘述照檔案順序執行：載入時就要跑的（讀網址、建 GL）放在用到它的檔之前；函式宣告不受順序影響。
- 拆檔那一次（2026-10-12）是機械搬移：各檔接回去 ＝ 原本的 `game.js`（逐字，只有 `return` → `throw` 一行），同一個種子 30 秒電腦對電腦、鏈彈打斷桅兩個情境的讀數逐項相同。

## 會咬人的地方

- **砲位**：從 `--parts` 的關聯路徑 `…/砲-S01`～`S14`、`砲-P01`～`P14` 認（兩舷各 14 門長砲）。砲口 ＝ 外框裡最外那一層的中心（S 那一舷 y 最大、P 那一舷 y 最小）。
  ⚠ 模型的 S（格 +y）在右手座標裡是船的**左手邊**（面向船頭 +x、上 +z ⇒ 右手是 −y；雕刻文件的剖面也是右手座標）⇒ 畫面上是左舷。程式裡的 `'S'`／`'P'` 照模型的名字，HUD、說明、A／D 一律照畫面（`sideName`）。關聯改名，砲就找不到。
  兩舷各有砲班、各自開火，**每一門自己判定**（`gunTarget`）：瞄準點在它的砲門射界（從砲口量、跟它的砲軸夾角 < 0.45 rad；舷側砲的砲軸 ＝ 那一舷正橫，追擊砲 ＝ 自己的砲管方向，正橫偏船頭 20°）就打瞄準點；不在，但敵艦船身（水線上那一段的中線、跟瞄準點同高，取 13 點）有一段在射界裡 ⇒ 打那一段裡離瞄準點最近的點；整艘都在射界外才不開。點在開火那一刻才挑（兩艘都在動）。讀數：敵艦在斜前方 25° 時瞄它船頭，舊規則（只看瞄準點）0 門、現在 27 門。
- **桅**：桅杆子作品的外框是整艘船（放在原點），認不出位置 ⇒ 從四種橫帆（`<fore|main|mizzen>-<course|topsail|topgallant|royal>`）推大概的 x，再在附近找中線上那根直立的柱子。
- **繩的錨**：兩端各找 0.5 公尺內最近的實心格；找不到的端點，落在模型外框裡 ⇒ 綁在模型上（舵索綁舵輪，模型飛了才斷），否則掛到端點旁邊那條繩上（ratline 掛在 shroud 上），靠著的斷了它跟著斷。哪裡都靠不到 ⇒ 不畫。
- **帆的依靠**：最高那一排、最低的前角與後角各找 0.6 公尺內的實心格；找不到就掛在 0.4 公尺內最近的繩上（三角帆掛在支索上）。任一個依靠沒了 ⇒ 帆掉下來（物理關著：變成十來片平面布片；開著：見下面「帆與繩的物理」）；依靠全在斷開的那一團 ⇒ 跟著倒。帆自己的繩（名字 `<帆名>.sheet-S`／`.tack-P`…）帆掉了或被帶走就跟著斷 —— 只靠繩的依靠不夠，sheet 與 tack 互相掛著、另一端綁甲板。
- **模型**：carronade（24）、追擊砲 chase18、舵輪；不在格子裡，被打到（外框＋0.15 m；鏈彈 1 m）或在爆炸 2.2 m 內 ⇒ 整個飛出去，腳下那一格甲板沒了 ⇒ 掉下去。兩舷各 12 門 carronade 與追擊砲也是砲：carronade 砲管軸在甲板上方 9.75 格、初速 140 m/s、裝填 0.7 倍；追擊砲朝 S 那一舷（畫面上的左舷）偏船頭 20°。
- **船員**（billboard，每艘 274）：兩舷每門長砲 6 人、carronade 3 人、追擊砲 4 人（24 磅長砲一班 12 人＋送藥童 ⇒ 一個人物約兩人）；送藥手、陸戰隊、軍官、舵手、桅頂水手。站位在載入時於格子上找（腳下實心、頭上 1.4 m 空、避開模型外框）。
  砲要有人操作：在崗人數 < 最少人數（3／2／2）不能開，裝填速度 ∝ (在崗／滿編)^0.85；人不夠時同一層甲板、同一舷（砲甲板 ＝ 長砲＋追擊砲；上甲板 ＝ carronade）集中：開得動的砲人不動；開不了的砲照人數多到少，向最近的空閒的人或同樣開不了的砲借人，借到能開就留下，借不夠的人放出來；空閒的人夠一整門才去開空砲，剩下的補滿（都挑最近的）。其餘沒人操作（HUD ○）。軍官全倒 ⇒ 瞄準散 1.7 倍。
  傷亡來源：碎木（洞的前方錐）、砲彈掠過、爆炸、火槍（陸戰隊與桅頂水手打對方露天的人）、腳下沒了落水、倒下的桅壓到、模型被打飛。
- **滑桿**：進水速度（`?flood=`，0–2，預設 0.35；0 ＝ 不會沉；進水與抽水一起縮放）、船殼硬度（`?hard=`，0.5–20，預設 2；滑桿是對數刻度；打穿的減速 ×硬度、洞 ×硬度^−0.25、鏈彈撕開的寬度 ×(硬度／2)^−0.25）。上下限與預設只有一份（`js/04_state.js` 的 `LIM`），網址參數照同一組夾、讀不懂 ⇒ 預設；滑桿被動過才讀回。
- **降旗**（選單設定，`?strike=60,guns,masts,officers`：數字是死傷百分比，後面列要勾的）：死傷門檻 10–100%（死傷 ＝ 傷＋亡）、砲全啞（毀了或沒人操作）10 秒、桅全倒且死傷 ≥ 33%、軍官全倒且死傷 ≥ 25%，任一條成立就降。預設 100%、全不勾 ＝ 不降旗：打到沉或全員倒下。降旗的船不再開砲（排在齊射裡還沒開的也取消），電腦對降旗或在沉的船停火。
- **航行**（選單或遊戲中 Tab／下方按鈕切「自動／手動／停船」，`?sail=manual`／`off`；停船 ⇒ 6 秒內停下、不轉舵）：航速 ＝ 3.6 m/s × 張著、還在的帆面積比例 × 風向係數 ×（進水越多越慢），加減速時間常數 20 秒；降旗 ⇒ 停船，沉了 ⇒ 0。
  風向係數照船頭跟風吹去的方向的夾角：0° 順風 0.72、45° 1、90° 橫風 0.92、112° 0.6、125° 0.32、180° 頂風 0.25（⛔ 沒做搶風／換舷：頂風只是慢，靠慣性帶過去）。風 ＝ `WIND`（也是煙飄的方向），開局兩艘大致橫風。
  自動操舵：讓敵艦保持在它現在所在那一舷的正橫（有遲滯；那一舷的砲都開不了就換另一舷對著它），太遠往敵艦偏、太近偏開（最多 0.4 rad）⇒ 兩艘都用同一舷 ⇒ 繞著彼此轉；一艘一舷 ⇒ 並肩同向。電腦等有砲對得到才開火。
  手動操舵（我艦）：A／D 是畫面上的左轉／右轉（自動或停船中一碰就換手動），打滿與回正各 0.7 秒；轉向率 ＝ 舵角 × 最大轉向率。轉向率 ∝ 航速，舵輪被打飛只剩 35%。
  帆裝（W／S）：全收（一面都不張 ⇒ 航速歸零、舵也慢慢沒效）／收帆（三面上桅帆＋jib）／戰鬥帆（再加上桅頂帆、後桅縱帆、前支索帆）／滿帆（全部，預設）；收起來的帆不畫、不算航速、**打不壞**：鏈彈打不到、依靠的格或掛的繩斷了也不掉 —— 只有桅（或上桅）斷了、依靠跟著斷開的那一團走時才跟著走；瞄準散布 × 0.7／0.75／0.85／1。
  選單滑桿「航速」「靈活性」（`?speed=`、`?agile=`，0.25–3，預設 1）：航速乘在 VMAX 上；靈活性乘在最大轉向率上，轉向率用除掉航速倍率的航速算（兩條各管各的）。
  兩艘的龍骨線（水線上船體的前後端之間各 7 點）最近不到 14 公尺 ⇒ 沿那個方向各推開一半、航速掉 3%（不穿船）。
  船在動 ⇒ 砲彈、碎屑、被打飛的模型、落水的人、放開的桅都帶著船速；砲手瞄「對方相對本艦」在飛行時間後的位置；齊射排隊的砲在開火那一刻才算瞄準點；繞斷口倒的桅斷口跟著船走。自由鏡頭預設跟著兩艘的中點平移（V 或下方按鈕關掉 ⇒ 固定）。
- **自動開砲**（`AUTOFIRE`，G／下方按鈕）：電腦替我艦挑目標、瞄準、開火（同一支 `ai()`）。觀戰模式 ＝ 一般戰鬥＋自動開砲預設開，其他模式預設關；觀戰也能自己操舵、開砲。
- **帆與繩的物理**（`PHYS`，B／下方按鈕／選單勾選，`?phys=0` 關；預設開）：
  - 帆是布（Verlet 質點＋距離約束），被**相對風**（`WIND` 的方向 × `WIND_SAIL` 7 m/s − 船速）吹鼓：轉向、頂風時整片往另一邊鼓。綁邊（帆桁／斜桁／支索那條筆直的邊）與帆腳是固定點，各自記著靠什麼（格、繩、模型）；靠的沒了那一點就鬆開 ⇒ 帆桁被打掉一截只有那一截鬆、帆腳的 sheet 斷了帆腳就甩。
  - 物理在**粗格**上算：雕刻作品的帆是規則格（方帆 25×25、三角帆第 r 列 25−r 點），取偶數列偶數行 ⇒ 13×13，畫的時候細格照權重內插回來（`coarseOf`）。一面帆隔一步走一次（30 Hz，兩艘一半一半輪流）。讀數：兩艘 30 面帆約 1.1 ms／步（細格是 5.4）。
  - 斷掉的繩不消失：從斷點分成兩段、各自掛在還綁著的那一端擺（`spawnLoose`）；整條鬆脫就往下掉，碰到甲板停住（`hitGrid`：落進格子就退回上一步），落水或 15 秒後拿掉。掉下來的帆同理（`dropSail` 只把帆標成不算數，布留著）；被鏈彈打到 ⇒ 布上開洞（`tearCloth`）＋撒布片。
  - ⛔ 物理只管畫出來的樣子：航速、命中、帆算不算數照原本的規則（`s.dead`／`s.furled`），而且物理不抽 `rnd()`（`dropSail` 的亂數照抽、只是布還在時不撒）⇒ 同一個種子開或關走出同一局（30 秒逐項對拍過）。`?demo` 快轉只在最後 6 秒開物理。
  - 帆的著色（`P.sail`，開關都一樣）：只畫一層（作品的帆是正反兩層、相差 0.11 格，兩層都畫遠看會打架成棋盤格）、頂點法線、包覆光＋逆光透光。
  - 讀數：`?debug=1` 的 `__game.cloth(艘)`（每面帆的粗格點數、綁點、離作品形狀最遠多少格、垂繩幾條）、`__game.prof()`（布／繩／緩衝各花多少 ms）、HUD 左下的「物理 x ms/步」。
- **預設鏡頭：我艦→敵艦**（`CAM.mode` 4，C 鍵循環的第一個）：注視點 ＝ 我艦中心，鏡頭在我艦背對敵艦的那一側 ⇒ 我艦在畫面中間、敵艦在它後方；兩艘繞著彼此轉時跟著轉。左鍵拖曳改相對這條視線的角度（`CAM.aoff`）與俯仰、滾輪改遠近；右鍵平移 ⇒ 換成自由鏡頭。`?cam=` 給了 ⇒ 那個固定機位（縮圖用）。
- **瞄準圈**：跟粒子同一支著色器，但另一批畫、關掉深度測試 ⇒ 瞄準點在敵艦遠側、被船身擋住也看得到。
- **鏡頭跟船**（`CAM.track`，V／下方按鈕，預設開；只管自由鏡頭）：自由鏡頭的注視點跟著我艦平移＋繞我艦轉、鏡頭角度跟著被看的那艘轉（看敵艦 ⇒ 敵艦）。⛔ 跟兩艘的中點：兩艘繞著中點轉圈，中點幾乎不動。
- **左下羅盤**（`drawNav`）：跟著鏡頭轉，「北」＝ 世界 −z、東 ＝ +x（航向照它算）；我艦、風（從哪吹來）、敵艦方位、兩舷射界（`anyBears` 對得到就亮），底下航向／航速／風向／船體／進水／傾斜／帆裝／舵。
- **船頭浪、船尾白沫、擦撞、電腦的瞄準範圍**：用水線上船體的前後端（`waterline()`，x 117–672）。⛔ 外框 `HULL_X` 含艏斜桅與後桅帆桁（x 11–958），船頭往前多出 28 m —— 用它的話船頭浪出現在船首前面的空水上、兩成瞄準點落在船頭前面。
- **水線**：吃水 63 格（同 basecamp《從一根龍骨開始》的下水段）。
- **預覽窗格在背景時** `requestAnimationFrame` 會停 ⇒ 模擬也停。量測用 `?debug=1` 的 `window.__game`（`start`／`run(秒)`／`fire`／`one`／`stats`（含航速、航向、位置、帆的比例）／`cam`／`strike({…})` 改降旗規則／`casualty(艘, 比例, 職位)` 讓人倒下）手動推進。
