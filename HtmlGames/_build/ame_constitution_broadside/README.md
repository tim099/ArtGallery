# 《憲法號對轟》的重產工具

`HtmlGames/ame_constitution_broadside.html` 是由這裡的 `template.html`、`js/`，加上共用的 `VoxelKit/` 產生的：

| 檔 | 做什麼 |
|---|---|
| `template.html` | 版面、HUD（下方的按鍵提示就是按鈕）、主選單（模式、航行、距離、帆繩物理、「細節設定…」與一行摘要）與細節設定頁（船殼、砲與每發傷害、彈種倍率、帆、船員、火藥桶、航行、降旗）；引用 `../../../VoxelKit/voxelkit.js`、`js/*.js`（照順序、`data-bundle="game"`）、船的 `.vxk` 與 `art/` 的選用素材 |
| `js/` | 遊戲本體，照功能分檔（下表）；建置時接成同一個閉包 |
| `art/`（選用） | 美術素材 `crew.png`、`fx.png`、`hud.png`；規格在 TASK-0516。沒交 ⇒ 程式畫的替代品 |

```bash
# ① 船：basecamp 的《憲法號（組裝）》，1:1，連繩、帆、模型、關聯外框、meta 與固定點（認砲、砲軸、彈藥庫爆心要用）
#    主要生產端是 senate（TASK-0518）；out 要絕對路徑
senate cmd sculpture --arg op=export --arg format=vxk --arg work=basecamp-frigate-constitution-01m-assembly --arg include=rig,models,parts,meta --arg out=<ArtGallery>/VoxelKit/_cache/constitution.vxk
#    （對拍用：python -I ../../../VoxelKit/voxel_export.py … --rig --models --parts --meta 出同一份，vxk_compare.py 比）
# ② 內嵌成單檔
python -I ../../../VoxelKit/vxk_inline.py template.html ../../ame_constitution_broadside.html
```

作品之後還會再長；重跑 ① 就拿到現況（`.vxk` 不入版控）。
⚠ 只改程式時，`_cache/` 裡的那份要跟版控裡成品內嵌的同一份，不然建出來換了船、縮圖 hash 也跟著變。另一台機器的 `_cache/` 可能是舊的 ⇒ 建置前先比一下內嵌的 `#ship`，不一樣就從版控那份成品的 `#ship`（base64）解回 `_cache/constitution.vxk`。

## 遊戲本體 `js/`

檔名前面的數字就是順序（template.html 照這個順序列，`vxk_inline.py` 照這個順序接）。各檔**沒有自己的作用域**：
建置時接成同一段、包進 `(function () { 'use strict'; … })()`，跟拆開之前是同一個閉包 —— 共用變數與函式、不掛到 window。

| 檔 | 管什麼 |
|---|---|
| `00_core.js` | 網址參數（`?demo`／`?seed`／`?debug`…）、有種子的亂數、常數、向量與矩陣小工具 |
| `01_gl.js` | WebGL 環境、著色器（體素、碎屑、模型、帆 `P.sail`、粒子、海、天）、共用 uniform |
| `02_audio.js` | 音效（按下開始後才建） |
| `03_camera.js` | 鏡頭（自由／追砲彈／看敵艦／看我艦、跟船）；追砲彈挑哪一顆（`pickBall`／`ballPredict`） |
| `04_state.js` | 全域狀態與選單設定：`LIM`（滑桿上下限）、硬度／進水／壓艙物／砲的重量／航速／靈活性、砲・帆・船員・火藥桶的血量、每發傷害 `DMG`、彈種倍率 `AMMO_K`、殉爆威力、降旗規則、模式、`PHYS` |
| `05_hull.js` | 船型（一種船一份，兩艘同型共用）：`HULL_LIST`（選單列得出來的船）、`loadHull`（選到才解碼、網格化）、`SHIP_SET`（我艦、敵艦的船型）、設計水線 `hullZW`（meta `kind=ship, waterline_z`，沒有 ⇒ 63） |
| `06_cache.js` | 船型快取（IndexedDB）：`cacheGet`／`cachePut`、快取鍵（`.vxk` 原文與頁面 JS 的雜湊） |
| `10_ship.js` | 開一艘船：模型（照 meta 認種類）、砲（模型＋固定點）、繩與帆的錨、桅、船員（`makeShip`）；模型照 x 分桶（`modelIndex`） |
| `11_rig_gpu.js` | 繩與帆的 GPU 緩衝（還綁著的繩、帆的網格 `sailBuf`、垂下來的繩） |
| `12_effects.js` | 碎屑（每格一顆小方塊）與粒子（煙、水花、火光） |
| `20_shatter.js` | 拆格：砲彈打碎船殼 |
| `21_gunnery.js` | 開砲、齊射、射界、砲彈飛行與命中、模型扣血與被打飛（命中照網格的佔用格 `inMesh`）、斷繩撕帆、帆掉下來 |
| `22_pieces.js` | 斷開的那一團：倒下、壓到人、落水；斷成兩截的半截船（翹起來、沉下去，上面的砲跟著走） |
| `23_powder.js` | 彈藥庫與火藥桶：血量、點燃、連鎖、整間殉爆（`crater`）、斷船（`breakShip`） |
| `30_rig_physics.js` | 帆與繩的物理（可關） |
| `31_sailing.js` | 航行：航速、操舵、帆裝、航跡、擦撞 |
| `32_hull.js` | 進水、傾斜、沉沒、減重上浮（`hydrostatics`／`massLost`／`liftFor`）；每半秒的 `survey`（砲、桅、繩、帆、腳下、少掉的重量）與降旗 |
| `40_crew.js` | 船員：站位、操砲、人手集中、血量與傷亡（`hurt`／`damageCrew`）、火槍 |
| `41_crew_art.js` | 船員貼圖（單圖；程式畫的替代品／美術素材）與程式動作（`crewPose`：晃、上下、縮放、傾斜、躺倒、閃紅）；手持物（點陣圖在程式裡畫，`heldItem`） |
| `50_sim.js` | 電腦（瞄準、開火）與固定步長的一步 `step()` |
| `51_captain.js` | 砲長：瞄準模式（水線／砲甲板／帆具／甲板人員／彈藥庫）、各砲長的偏好與換模式（`captainThink`）、模式要瞄哪裡（`modeAim`） |
| `60_render.js` | 畫一格 |

| `69_prefs.js` | 設定存檔（localStorage）：載入時套用、每秒比一次有變才寫（`prefsSnap`／`prefsApply`） |
| `70_flow.js` | 開局（`reset`／`start`） |
| `71_input.js` | 輸入與選單（鍵盤與畫面上的按鍵按鈕共用 `doKey`、滑鼠、觸控（雙指張合縮放、雙指一起拖平移 ＝ 右鍵拖曳，`panBy`）、滑桿、彈種倍率表、主選單 ⇄ 細節設定頁、重設預設值） |
| `90_main.js` | 主迴圈、`?debug=1` 的 `window.__game`、載入 |

- ⛔ 新的頂層名字先搜一遍有沒有撞名（同一個作用域：以前船員的 `kill` 蓋掉碎屑的 `kill`）。
- ⛔ 頂層的敘述照檔案順序執行：載入時就要跑的（讀網址、建 GL）放在用到它的檔之前；函式宣告不受順序影響。
- 拆檔那一次（2026-10-12）是機械搬移：各檔接回去 ＝ 原本的 `game.js`（逐字，只有 `return` → `throw` 一行），同一個種子 30 秒電腦對電腦、鏈彈打斷桅兩個情境的讀數逐項相同。
