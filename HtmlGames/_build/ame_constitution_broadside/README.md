# 《憲法號對轟》的重產工具

`HtmlGames/ame_constitution_broadside.html` 是由這裡的 `template.html`、`js/`，加上共用的 `VoxelKit/` 產生的：

| 檔 | 做什麼 |
|---|---|
| `template.html` | 版面、HUD（下方的按鍵提示就是按鈕）、主選單（模式、航行、距離、帆繩物理、「細節設定…」與一行摘要）與細節設定頁（船殼、砲與每發傷害、彈種倍率、帆、船員、火藥桶、航行、降旗）；引用 `../../../VoxelKit/voxelkit.js`、`js/*.js`（照順序、`data-bundle="game"`）、船的 `.vxk` 與 `art/` 的選用素材 |
| `js/` | 遊戲本體，照功能分檔（下表）；建置時接成同一個閉包 |
| `art/`（選用） | 美術素材 `crew.png`、`fx.png`、`hud.png`；規格在 TASK-0516。沒交 ⇒ 程式畫的替代品 |

```bash
# ① 船：basecamp 的《憲法號（組裝）》，1:1，連繩、帆、模型、關聯外框、meta 與固定點（認砲、砲軸、彈藥庫爆心要用）
#    主要生產端是 senate（TASK-0518）；out 要絕對路徑
senate cmd sculpture --arg op=export --arg format=vxk --arg work=basecamp-frigate-constitution-01m-assembly --arg include=rig,models,parts,meta --arg out=<ArtGallery>/VoxelKit/_cache/constitution.vxk
#    （對拍用：python -I ../../../VoxelKit/voxel_export.py … --rig --models --parts --meta 出同一份，vxk_compare.py 比）
# ② 內嵌成單檔
python -I ../../../VoxelKit/vxk_inline.py template.html ../../ame_constitution_broadside.html
```

作品之後還會再長；重跑 ① 就拿到現況（`.vxk` 不入版控）。
⚠ 只改程式時，`_cache/` 裡的那份要跟版控裡成品內嵌的同一份，不然建出來換了船、縮圖 hash 也跟著變。另一台機器的 `_cache/` 可能是舊的 ⇒ 建置前先比一下內嵌的 `#ship`，不一樣就從版控那份成品的 `#ship`（base64）解回 `_cache/constitution.vxk`。

## 遊戲本體 `js/`

檔名前面的數字就是順序（template.html 照這個順序列，`vxk_inline.py` 照這個順序接）。各檔**沒有自己的作用域**：
建置時接成同一段、包進 `(function () { 'use strict'; … })()`，跟拆開之前是同一個閉包 —— 共用變數與函式、不掛到 window。

## 會咬人的地方

- **船型**（`05_hull.js`；Tim 2026-10-12：basecamp 在造新船「餘燼號」，主選單要能選船、預設只載憲法號）：一種船一份 `T` —— 原始格子 `T.base`、合併過的網格 `T.pristine`、繩帆模型 `T.rig`、模型網格 `T.meshes`、桅 `T.masts`、帆的布模板 `T.cloth`、水線 `T.wl0／wl1／bowHalf`、海面遮罩 `T.hullTex`、浮力表 `T.hyd／disp`、中線與外框與設計水線 `T.cx／cy／hx0／hx1／zw／sz`；每艘船 `sh.T` 指向它的船型，模型、飛出去的模型、斷開的那一團也帶著 `T`（找網格用）。⛔ 船型是共用的、不能改（被打掉的格子在 `sh.grid`）。公尺／格 `S` 每種船都要一樣，不一樣就不載。海面著色器每艘一張遮罩（`uHull0／1`）。內嵌的 `.vxk` 只在被選到時才解碼（資料還是包在同一個 HTML 裡：畫廊的 iframe 讀不了旁邊的檔），省的是解碼與網格化（憲法號 0.08＋1.24 秒；讀快取 0.07 秒，見下）。拆的時候對拍：`?demo=75&still=1&cam=deck` 拆前拆後逐位元組相同。
  - **船型快取**（`06_cache.js`，IndexedDB；Tim 2026-10-13）：存載入時算一次、之後不改的 —— 船體網格（每個區塊的四邊形）、模型網格（三角形＋佔用格）、海面遮罩、浮力表、帆的布模板。格子不存（解碼快，checksum 照解出來的比）；GPU 上傳每次照做。一型一筆。快取鍵 ＝ 內嵌 `.vxk` 原文的雜湊（重匯、改繩帆模型都會變）＋ 頁面 JS 原文的雜湊（改任何一行程式都清）＋ 格式版本；對不上 ⇒ 現場解析完蓋掉。存不了（畫廊彈窗、無痕）⇒ 照常解析。`?cache=0` 不讀不寫。讀數：載入那一行寫「讀快取 N 秒」或「現場解析；為什麼」，`window.__vxk.ms` 是各段毫秒。

  - **進到主選單才解析**（Tim）：主選單先畫出來（畫面迴圈一開始就跑，天與海照畫），解析分五步（格子／模型網格／水線與浮力／船體網格／桅與帆），每步之間讓出一次（`yieldUI`：MessageChannel；⛔ 不用 setTimeout：分頁在背景時會被壓到一秒一次）；開戰鈕寫「解析憲法號：船體網格（4／5）…」，這段時間設定照樣能調。
  - **船隻設定**（照船型套，Tim：不同船套用不同設定）：硬度、進水、壓艙物、砲的重量、航速、靈活性 —— `SHIP_CFG[船型]`，開戰時複製到每艘（`sh.cfg`）；被打的那艘照自己的硬度。細節設定的「船隻設定」先選編輯哪一型；網址的 `?hard=` 等等套到每一型；壓艙物沒給 ⇒ 那一型剛好浮在設計水線（`T.ballast0`，照實的砲重、取用點 12 桶、每格 0.7 kg，四捨五入到 25 噸：憲法號 1,075）。「重設預設值」⇒ 每一型回到它自己的預設。
