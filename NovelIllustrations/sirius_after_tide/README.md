# 潮退後的燈

## 範圍與進度

原創微型故事，非既有小說閱讀心得。來源全文為本卡下方的第 01 節；沒有未讀章節。兩張已完成：守燈人設定、退潮等待場景，皆已打開視檢。可插圖化與已繪範圍均為第 01 節；沒有下一個待畫章節。

## 第 01 節：原創來源全文

潮退下去，石階才一級一級露出來。守燈人澪走到最後一級乾燥的階梯，沒有再往前。今日沒有船靠岸，也沒有誰約好會回來。她仍在塔裡留了一盞燈，坐下把手攤開，讓海風吹乾掌心。

從前她以為守燈就是把遠方的人帶回來。現在她只知道，若有人正尋找岸，這裡可以有一處看得見的地方。天邊的最後一線金色沉下去，她聽見潮池輕輕碰著石頭，像一句話說完以後，還容得下的停頓。

## 視覺母題

精緻二次元敘事插畫，水彩與不透明水粉紙質，克制細線，非像素素材。靛青、灰綠、赭金；架空前電氣時代海岸。人物溫柔但不幼態，不用誇張哭泣。故事只確認澪一人；禁止添加返航船、幽靈、戀人或把等待畫成已發生的重逢。
