## 視覺母題

沿用第一冊的潮濕黑石、海風、羊毛與磨舊皮革，但本章把暖色集中在黠謀國王臥房的壁爐、濕布與照料動作；高窗外的冬日藍灰光保持距離。畫面採寫實的奇幻書籍插畫質地，無文字、無水印，不把精技視野畫成魔法特效。

## 待建與尚未鎖定

本章的泥濘灣只以蜚滋的精技視野出現；紅船、火災與居民的死亡不可被當作一張可驗證的現實場景重畫，因此本輪不建立泥濘灣街景或新的劫匪人物卡。弄臣的身分、預言能力與鼠頭權杖的用途仍只鎖定本章可見行為，不替後續章節補完。下一次開工先讀第二章，確認公鹿堡歸鄉場景是否需要新增旅途或城堡設定。
