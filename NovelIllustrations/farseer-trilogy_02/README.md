## 待建與尚未鎖定

第一章的泥濘灣只以蜚滋的精技視野出現；紅船、火災與居民的死亡不可被當作一張可驗證的現實場景重畫，因此不建立泥濘灣街景或新的劫匪人物卡。弄臣的身分、預言能力與鼠頭權杖的用途仍只鎖定前三章可見行為，不替後續章節補完。第三章沒有新增設定卡：惟真與莫莉均沿用第一冊已存在的角色設定，場景圖選擇莫莉重逢的門邊距離，避免把未解的關係畫成和解。第五章的小狼已完成設定與心得場景圖，畫面將照顧保留為可退出的暫時庇護，而非馴服或既定歸屬。第六章的惟真地圖室已建立為可重複引用的場景設定；紅蠟標記只表示可疑襲擊，不能被解作真相。第八章新增珂翠肯人物設定，畫面只鎖定她以葬禮取代復仇的領導行動，不補完毒殺陰謀與後續王室事件。第九章沿用蜚滋與小狼設定，場景停在雪地玩鬧後的選擇，不把狼群或公鹿堡判成唯一正確的家。第十章補上珂翠肯的安靜起居室設定與兩張矮凳之間的心得場景；原智只作為人物關係中的細微感受，不畫成特效。第十一章更新小狼設定為夜眼，場景停在雪地救援後的兄弟承認，不展示被冶鍊者屍體或後續精技／古靈答案。第十二章新增烽火台王后花園設定與雪中初見場景；花園只停在被雪掩埋、尚待整理的冬季遺跡，不提前畫出後續修復成果。第十三章沿用蜚滋、惟真與博瑞屈設定，新增狩獵後房間的場景設定；心得圖只畫清理、照料與責任辯論，不畫小女孩、母親、被冶鍊者或血腥戰鬥。第十四章沿用蜚滋、黠謀與臥房設定，心得圖只畫開窗、清理、熱茶、糕點與承諾，不畫帝尊衝突或更後續王室事件。第十五章新增烽火台斧術訓練場設定；心得圖只畫蜚滋、博瑞屈與惟真在冬晨共同承擔抵抗的瞬間，不把弄臣的未來預言畫成已確定的命運。第十六章的白船只保留為蜚滋個人目擊：場景圖呈現感官連結突然中斷與無法確認的船影，不將詛咒、敵方身分或後續劇情視為已知。第十七章新增婕敏捎來的古靈捲軸設定，外觀只保留黃色緞帶、綠蠟封口與殘缺抄本；心得圖停在蜚滋手持捲軸與黠謀病弱相對，不描繪可讀內容，也不把照料與政治安排互相抵銷。第十八章新增耐辛藥草起居室設定；心得圖只呈現蜚滋在垂掛葉束間停手思索，不替藥草指定療效，也不畫出莫莉未曾在場的場景。第十九章沿用蜚滋與珂翠肯設定，畫面停在她聽見近鄰群島遭割讓的說法後，蜚滋請她先等證據、再查明真相；不把流言或政治疑點預先裁定為陰謀。第二十章沿用蜚滋與莫莉設定，心得圖停在舊情揭露後的並肩相握，不把短暫靠近誤寫成出走、承諾或關係已和解。第 004 章仍待補圖，下一次接續第 021 章。
