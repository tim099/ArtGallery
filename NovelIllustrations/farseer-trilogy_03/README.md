# 《刺客任務》小說插圖製作台帳

## 範圍與視覺母題

已讀至第三十二章〈胡瓜魚海灘〉全文並完成場景圖；下一次接續第三十三章。閱讀進度以 Library 中 meadow 的 `book-farseer-trilogy_03` reader 為準。

沿用系列的磨舊木材、粗紙、冷灰陰影與有限暖光，寫實奇幻書籍插畫，無可讀文字與水印。序曲呈現寫作與記憶並存，不能把工作畫成痊癒或苦難已結束。晨光、桌面材質與墨罐樣式屬視覺詮釋，不冒充正文指定物件。

第一章把照顧與強迫、關心與能力期待留在同一幅閱讀理解裡。水碗只呈現清水與藍釉底，不把沒有異象畫成能力恢復；燭光、粗陶外壁與蠟燭數量屬視覺詮釋。

第二章以重新扶起的木椅和微弱爐火保留照顧與裂痕，不將回來畫成和解，不將蜚滋的復仇決定畫成自由已完成。木椅形制、靴子外型與場景配置屬視覺詮釋。

第三章首次建立成年夜眼設定，以屋外長嗥保留同伴與孤獨的並存。月光只作自然照明，不把原智畫成藍光或人狼融合；小屋、林緣與月亮方位屬視覺詮釋。

第四章建立復原期蜚滋旅人設定，与成年夜眼形成首次人狼擁抱構圖。以空衣領保留胸針失落，以露喉回應尚不能完全理解的痛；微火、暮色與溪岸配置屬詮釋，不把靠近畫成創傷已消失。

第五章以戰鬥前的徒手捕魚保留人的手也能準備晚餐的日常。兩名主體沿用既有設定，不提前加入夜眼左肩劍傷或蜚滋後來取得的長劍；魚種、溪流布局、樹種與光線屬插畫詮釋。

第六章先建立夜眼左肩受傷狀態，以小屋地面上共同安睡保存有人看護的具體照顧。傷仍在，不把休息畫成痊癒；地面材質、相對睡姿與午後光線屬詮釋，屋主及其他動物在畫外。

第七章補蜚滋收起襯衫後的旅途頭肩設定，以独坐酒河岸邊的近景與河面留白呈現容許朋友離開。夜眼與狼群不入畫，不預告團聚或永久訣別；河形、岸草與夜光屬詮釋，非固定地理設定。

第八章先建立商業灘殿堂外景，以低牆外的观看位置保存美的嚮往與受保護的距離。住宅不改成要塞，海岸戰爭、吾王廣場與精技夢不疊进花園；幕光與庭園配置屬詮釋。

第九章先建立箭兒黑馬設定，以逃亡後無騎士的離去保存信任與未完成的事。馬兒回到馬廄與追兵誤信死訊均未確定；溪岸、小徑與日光屬詮釋，不將分別當作已經安全。

第十章先建立自由人藍寶石耳環設定，再以小片絲布上的近景表達留下過往的具體連結。人物與手在畫外；寶石不發光，來源不補定。木材支承、河面光線、絲布顏色與小鉤編織細節屬詮釋，不把收好耳環畫成旅費或安全問題已解決。

第十一章先建立厚實紅陶杯，以晚餐後營火旁兩杯並置保留短暫的友善。人物、傷口與之後衝突全在畫外；杯形、把手、石面安放位置、暮色與模糊貨車為詮釋。照料不等於塔絲獲自由，也不替蜚滋保證回家。

第十二章以沙地中的鑰匙保留求生與責任並存：只有一枚小物件，不畫勝利光束，不將開鎖視為赦免。沙粒、低角度夕照、金屬材質與鑰匙精確輪廓為詮釋。

第十三章以屋頂上的小白鼬與乾肉保存失去之後仍能送達的援手。微霜屋瓦、象牙白毛、黑尾尖、低光與排列屬詮釋；不畫復仇成敗，不把短暫餵食視為悲痛已治癒。

第十四章沿用耳環設定，在爐火前被拎起的微距近景保存割捨的代價。只有裁切邊緣少量指尖，人物不可辨認；寶石不發光，不畫渡河或已交付的結果。

第十五章以夜眼頭頸近景保留雪夜重逢與召喚束縛的並存。雪已停、風仍吹；不把精神約束實體化為籠子或魔法線。裁切在肩部之前，舊左肩傷未明確确认復原，不畫成痊癒。

第十六章先建立雪河岸場景，引用成年夜眼的頭頸近景，保存蜚滋開始先看見一匹狼、再看見同伴的尊重。肩部與四肢在畫外，舊肩傷復原程度仍不補定；河流仍湍急、對岸未抵達。觀看角度與陰天冬日光為詮釋，沒有合成獵物遊戲、催化劑文獻或紅船精技夢。

第十九章先建立女兵私人小物設定，再畫冷杉下覆土前的近景，保留匿名追兵也有私人生活。材質、髮色與骰子數量為詮釋，不補髮束來源，不把埋小物畫成赦免；人物與狼在畫外，不合成後段箭傷求生。

第二十章先建立頡昂佩弄臣的當章外貌，床邊落淚圖採單人頭肩近景，保留有限的重逢喜悅，不將角色使命與預言畫成已證實結果。蜚滋和箭傷在畫外，暫時安全不是痊癒；不合成章末額頭相靠。

第二十三章建立惟真留下的古地圖設定，以帳篷火光下地圖與一隻匿名指路手的近景呈現：路徑分岔，端點模糊，人物身分不入畫。羊皮紙與花飾格線依正文；磨損、燈色與毯面屬詮釋，不替古道標出目的地，也不洩漏後續地形。

第二十四章先建立沒有足跡的古道場景設定，再畫林緣營火與筆直雪路的空景。蜚滋、同伴與動物都在畫外；平整雪路、古樹與火光依章內情境，不畫可見魔法，也不把水壺嬸提及的古老傳說定為道路真相。

第二十五章新增古老公鹿石棋設定，以黑石落在關鍵交點的近景呈現夜眼將棋局看作狩獵隊伍。盤面全貌與石子位置是詮釋，不宣稱重現未列出的精確棋局；不畫人物、狼或字面魔法。

第二十六章引用成年夜眼頭頸設定，以帳篷內狼頭靠在腿上、手搔耳後的近景保存原智交流中斷時仍能理解的碰觸。人物臉與肩傷部位不可辨識，不補復原結果；暖光與布料為詮釋，不合成救援、幻象旅人或章末圓柱。
