# 《英倫魔法師》小說插圖設定集

## 視覺母題

十九世紀初攝政時期英格蘭北部約克郡的厚重沉靜質感。以冷灰石材、潮濕石階、蜂蠟打磨橡木、哥特拱頂雕花書架與溫暖壁爐火光為基調；第二至三章呈現大雪覆蓋全城的清冽純白、約克大教堂高聳石柱間的瓦藍水綠天色、以及石雕活化時揚起的石灰沙塵與奇異微光。色彩以原色小牛皮皮革、深褐毛料、暗紅天鵝絨、純白積雪、石灰冷灰與陰鬱墨黑交織。設定稿維持經典英國歷史奇幻插畫油畫質地、筆觸細膩、無文字、無水印。
