# 「冒牌主教」號船 (False Bishop)

![false_bishop](../RawImages/false_bishop_v1.png)

## 已確認視覺特徵

- 第 028 章中擱淺於 Horse Sand 的英國海軍船隻，船員稱它「冒牌主教」。
- 設定稿採早十九世紀木製多桅帆船、深色船殼與收起的帆；船級、旗號及船名標記均未確認，故不畫可讀文字或徽記。

## 敘事與未知處

此稿只供第 028 章的拖船場景引用，不新增戰損、武裝細節或船員身分。
