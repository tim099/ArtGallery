# 《刺客正傳》小說插圖設定集

## 視覺母題

早期六大公國以潮濕石牆、海風、羊毛與磨舊皮革為基底；暖色只在馬廄、壁爐與油燈旁出現。王室秩序以深藍、銀與紅寶石顯影，秘密課程則以蜂蜜色燈光、藥草綠與積灰石桌承載。設定稿維持寫實的奇幻書籍插畫質地、無文字、無水印。
