# 花札牌局設定稿

**已確認外觀：** 榻榻米上攤開的花札牌組、木製牌盒與簡單的計分籌，牌面是季節花卉與動物的圖樣。設定稿刻意不包含手、玩家或可讀文字，讓後續場景能依需要加入不同對局者。

**敘事功能：** 這不是賭博的裝飾，而是《夏日大作戰》把帳號權限轉成可見規則的介面：不靠暴力搶回，而必須在同一套被承認的玩法裡贏回來。後續構圖可取牌局局部，但應保留榻榻米、花牌與木盒的親密尺度。
