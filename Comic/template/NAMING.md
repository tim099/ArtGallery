# 正名表與畫面文字規則

## 一、正名表（**給 prompt 用** —— 讓模型不必腦補，不是授權畫上去）

| 對象 | 正名（中） | 外語 | ❌ 絕不可出現 |
|---|---|---|---|
| 主角 | `<名>` | `<Name>` | |
| 船／載具 | `<名>` | `<Name>` | |
| 地名 | `<名>` | `<Name>` | |

> ⚠ **這張表是餵給模型用的，不是准許把這些字畫上去。**
> 給它名字是為了讓它**別瞎編**（否則它會自行腦補一個相近的詞），不是為了讓它寫出來。
> 畫面上准出現什麼看 §二。
>
> 拼法有疑問時**不要猜，回頭問原作** —— 錯的拼法印上去就是正典，
> 而下一張圖會拿它當參考，**錯誤會自我繁殖**。

## 二、畫面上的文字

### 二之一、文字住 `.md`，不進畫面

**閱讀介面是 `Chapters/NNN.md`**（圖在上、分鏡文字在下），畫面不需要把同一批字再寫一次。

| 文字 | 住哪 |
|---|---|
| `字幕：`／`角色「」` | **`.md`** |
| 畫面裡**本來就存在**的字（招牌、旗幟紋樣） | 畫面 |
| 擬聲詞 | 畫面，但小、貼著畫面 |

這讓三件事同時消失：語言排版、文字滲漏、prompt 過載。

### 二之二、一律不准出現

| | |
|---|---|
| ❌ | **角色姓名標籤**（`NAME (16)` 那種）—— 那是設定集的做法不是漫畫 |
| ❌ | **頁碼** —— 頁次由檔名管 |
| ❌ | **版面詞**：`TOP PANEL` / `BOTTOM PANEL` / `PANEL 1` |
| ❌ | **方括號指示**：`[SFX: …]` / `[SOUND EFFECTS: …]` |
| ❌ | 任何 **prompt 原文碎片**（`manga panel`、`ink line art`…） |
| ❌ | `<本作專屬：例如「船身不標船名」>` |

## 三、語言與版面

- **版面**：`<右開き／左開き>`
- **語言**：`<…>`
- 基準頁：`<某一張已驗收的乾淨頁>` —— 判斷新頁有沒有跑掉，**跟它並排比一次**比重讀規格快。

## 四、擬聲詞

`<本作的規則：小／大、哪種語言、哪些格禁止>`

## 五、寫 prompt 時的手勢

1. **指示與內容分開送** —— 版面／景別／SFX 的結構描述**不進要求生成畫面文字的那一段**。
   判準不是「記得別讓它印出來」（那要人記得，而人會忘），是**結構詞根本不在那裡**。
2. **專有名詞從 §一 複製貼上**，不憑記憶打；**同段要一併講死畫面上不出現哪些字**。
3. **掛參考圖優先於文字重建** —— 角色、船、場景、道具都掛設定圖。
   要掛哪些看該話 frontmatter 的 `characters:` / `props:`。
4. **交件前把圖打開，掃一次「畫面上有沒有字」** ——
   字幕既然住 `.md`，畫面幾乎不該有文字，**看到字就先當異物**。

## 六、維護

- 新角色／新地名進場前，**先加進 §一** 再開畫。
- 發現新的滲漏樣式就補進 §二之二 ——
  **用結構規則寫，不要只列這次看到的那幾個字**（具名白名單只擋得住你當時想到的名字）。
