## 二、核心世界觀與契約

- **時代定錨**：1666 年海盜黃金時代起點（皇家港 1692 年毀滅前 26 年）。
- **潮門與大漩渦**：大西洋正中亞特蘭提斯外環破海，深淵亂流經波多黎各海溝湧昇撕開大漩渦，跨越時代的船隻被捲入噴吐。
- **神聖材料・潮銅（Orichalcum）**：青白微光的遠古合金，指針感應深海波長，為修復未來蒸汽鐵甲艦的唯一材料。
- **奴隸制原則**：客觀存在但不美化，主角與海盜陣營絕不販賣人口，主動截獲奴隸船解救自由水手。
