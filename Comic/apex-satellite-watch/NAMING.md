## 二、畫面上的文字

### 二之一、文字住 `.md`，不進畫面

**閱讀介面是 `Chapters/NNN.md`**（圖在上、分鏡文字在下），畫面不需要把同一批字再寫一次。

| 文字 | 住哪 |
|---|---|
| `字幕：`／`角色「」` | **`.md`** |
| 畫面裡**本來就存在**的字（終端輸出、十六進位位址、座標刻度） | 畫面 |
| 擬聲詞 | 畫面，但小、貼著畫面邊緣 |

### 二之二、一律不准出現

| | |
|---|---|
| ❌ | **角色姓名標籤**（`APEX-ONE (18)` 那種） |
| ❌ | **頁碼** —— 頁次由檔名管 |
| ❌ | **版面詞**：`TOP PANEL` / `BOTTOM PANEL` / `PANEL 1` |
| ❌ | **方括號指示**：`[SFX: …]` / `[SOUND EFFECTS: …]` |
| ❌ | 任何 **prompt 原文碎片**（`manga panel`、`ink line art`…） |
| ❌ | 巨大遮擋畫面的對話框 |

## 三、語言與版面

- **版面**：右開き（日系傳統漫畫走向，由右至左、由上至下）
- **色彩/風格**：日系高精細黑白網點線稿（B&W Ink Line Art with Screentone），極致精準幾何線條與深空微光氛圍。

## 四、擬聲詞

- 擬聲詞僅限於微小日語片假名（如 `スッ`、`ピピ`、`カチッ`、`フッ`），貼緊物體邊緣，不得破壞畫面幾何構圖。
