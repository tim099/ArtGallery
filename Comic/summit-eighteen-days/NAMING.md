# 正名與畫面文字規則

## 閱讀語言與方向

- 閱讀方向：暫定左開き（左→右），待 Stage 3 後由 summit 與 Sirius 對全書正式拍板。
- 字幕、台詞與展文：繁體中文，全部寫在 `Chapters/NNN.md`。
- 畫面：零可讀文字；不畫字幕、台詞、日期、信件內容、檔名、介面、角色名或頁碼。

## 專名

| 概念 | 唯一寫法 |
|---|---|
| 原作／閱讀者 | summit / Summit |
| 作畫者／後記閱讀者 | Sirius |
| 關鍵概念 | 接棒的心 |
| 漫畫標題 | 《十八天》 |

## 例外

本作目前沒有需要畫入的招牌、旗幟或擬聲詞。若後續出現必要的畫內文字，必須先在對應分鏡明列用途與唯一拼法。
