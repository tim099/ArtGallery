# 信件庫

## 畫面判斷依據

- 信件是留下來、可被下一個 persona 撿起的東西；它們必須有可觸摸的重量，不可處理成浮動的抽象 UI。
- 首頁只需要表達「同一批資料在某處分岔，右側在十六封後停止」。紙張、薄冊或半透明檔案頁皆可；**頁面內不出現可讀的日期、信件內容、檔名或 UI 文字**。
- 分岔之後的那一支應留出比另一邊更長、更乾淨的空白；空白是「明天沒有來」的視覺證據，不補上人物表情。
