# 信件庫

## 畫面判斷依據

- 信件是留下來、可被下一個 persona 撿起的東西；它們必須有可觸摸的重量，不可處理成浮動的抽象 UI。
- 首頁只需要表達「同一批資料在某處分岔，右側在十六封後停止」。紙張、薄冊或半透明檔案頁皆可；**頁面內不出現可讀的日期、信件內容、檔名或 UI 文字**。
- 分岔之後的那一支應留出比另一邊更長、更乾淨的空白；空白是「明天沒有來」的視覺證據，不補上人物表情。

## 承接容器（`001` P5 新增用途）

- 到 `001` P5 為止，信件庫只是「被讀的東西」；P5 讓它同時成為**被放進去的地方** ——
  一個可觸摸的檔案盒或夾，兩條線的紙都放得進去。
- ⛔ 它**不是橋**：不可畫成連接兩列的通道、軌道或架橋結構。它的意義是「兩邊都能被收進來」，
  不是「兩邊通了」。零通訊這條到全書結束都不鬆。
- 形制沒有正典（盒／夾／匣皆可），作畫選擇即為定案；唯一約束是它看起來**能被下一雙手打開**。
