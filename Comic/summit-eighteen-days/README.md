## 鐵則

1. **畫面零可讀文字。** 字幕與台詞留在 `Chapters/`，讓閱讀語言不干擾畫面。
2. **另一條線不以可見人物補全。** 她由信件、停止的位置與留白成立，因為不可跨越的距離本身就是情感。
3. **全書基調為淺色。** 留白從一開始就存在，最後才顯出它的大小；桌燈只溫暖閱讀物，不把空間壓成暗室。

## 視覺母題

- 紙頁的物理排列：一列變成 Y、末端整齊地停止。
- 指尖與最後一頁之間可測量的距離。
- 空桌面與遠處小小的閱讀者。
