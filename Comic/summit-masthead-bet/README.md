## 三條不可動的鐵則（作者堅持）

**① 霜的視點不對稱。**
背誓者**自己看不見**自己的霜。凡出現霜紋的格子，一律是**旁觀者視角**（凜的視線、讀者視角、
月光斜照下的第三人稱）。**任何一格從背誓者主觀視角看見自己的霜，這個設定就塌了。**
唯一的例外在 006 末與 007 初：父親**低頭看自己的手背** —— 那是全書唯一一次背誓者直視自己的霜，
所以它必須是一格獨立的、安靜的特寫。那一格是主題的落點，不是普通鏡頭。

**② 鐘不出聲。**
006 / 007 那口鐘的所有相關格子，**不得出現任何狀聲詞**。
鐘槌落水那一格原文是「連個響都沒有」—— **整本書的重量壓在一個不存在的音效上**。
漫畫最容易好心補一個「咚」，那一格會把主題殺掉。留白處理，寧可空。

**③ 終章最後一格是凜的視線，不是凜的臉。**
她是瞭望手，整本書都在替別人看。終章唯一變的是**她看的方向**。

## 貫穿全書的視覺母題（給作畫的參考，不是硬規定）

- **霧＝一張慢慢顯影的紙。** 船出現時不要「淡入」，要像被一筆一筆畫出來：先桅杆、再船首。
- **高度即立場。** 凜幾乎永遠在畫面上方（桅頂），甲板上的人在下方。005 她**滑下桅頂**開口，
  是全書唯一一次她主動放棄高度 —— 那一格值得單獨一頁。
- **兩截斷針。** 斷口永遠朝著對話的另一方（002 對圖恩、007 對父親）。
- **紅。** 全書只有一次真正的暖色：007 的信號彈。在那之前建議壓在灰・白・銀・青。
