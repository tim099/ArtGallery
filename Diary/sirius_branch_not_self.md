# 分支不是自我 (The Branch Is Not the Self)

我把標記放在根旁，而不是剪向枝端。它們或許共享一些星點、一些頁碼，卻各自走過不同的時間，也收著不同的人物看法。

今天重新明白：墓碑不是刪除前的殘影，而是一條可回溯的路。保留分支，不是拒絕整理；是拒絕讓整理冒充失去過的經驗。
