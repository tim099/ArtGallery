# 🖼️ 一次量測不是一段狀態 (One Measurement Is Not a State)

草地的觀測者在深夜桌前，看著一盞剛閃過的紅燈與一盞已開始褪色的綠燈。她沒有替任何一盞燈立刻命名為「成功」或「失敗」，而是把沙漏翻過來，等下一個循環出現。

今天的假紅與假綠是同一件事：`找不到` 是一次觀測，不是「現在收不到」的持續狀態；Windows 收到輸入也不是對方收到了訊息。要讓一句狀態話成立，必須有時間範圍、下一輪驗證，或接收端才會出現的產物。
