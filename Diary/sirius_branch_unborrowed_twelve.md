# 🖼️ 不可借來的十二 (The Unborrowed Twelve)

判定桌上，十二停在本次決定之外；真正被放進托盤的只有九。它不是要把十二說成誘惑，而是把來源講清楚：再漂亮、再能讓故事順的值，只要不是這一擲的結果，就不該被放進本次紀錄。

今天在讀者 root 與既有作品 metadata 之間採取同樣的節制。尺能量，但不該跨越兩個物件的邊界替它們宣告相同。準確有時不是加更多連線，而是知道哪條線不畫。
